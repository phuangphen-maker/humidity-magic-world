# Humidity Magic World: ผจญภัยอาณาจักรเวทมนตร์แห่งความชื้น

เกม Three.js แบบ third-person สำหรับวิทยาศาสตร์ ม.1 มี 7 ด่าน คำถาม 21 ข้อ (ข้อละ 10 คะแนน รวม 210 คะแนน) สร้างแยกใน repository นี้ ไม่เกี่ยวข้องกับ Wind Kingdom

## ติดตั้งและรัน

ต้องมี Node.js 22+ (ทดสอบด้วย 24) และ npm

```sh
npm ci
npm run dev
```

เปิดที่อยู่ที่ Vite แสดงในเครื่องของคุณ ต้องใช้เบราว์เซอร์ที่รองรับ WebGL2 เปิดเสียงจากปุ่มเพลงหลังผู้เล่นโต้ตอบครั้งแรก ฟอนต์ออนไลน์เป็นตัวเลือก มี Tahoma/sans-serif สำรอง โมเดลทั้งหมดสร้างจาก geometry ไม่ต้องดาวน์โหลดโมเดลหรือใช้ API key

## วิธีเล่น

กรอกชื่อ–นามสกุล ห้อง และเลขที่ เลือกพ่อมด/แม่มด ใช้ W/A/S/D เดิน, Shift วิ่ง, Space กระโดด, E โต้ตอบ มือถือใช้จอยสติ๊กและปุ่ม แนะนำแนวนอน

แต่ละด่านมีคริสตัล 3 ดวง เหรียญเสริม 9 เหรียญ แท่นทดลองอยู่กลางทาง เข้าใกล้แล้วกด E เดินใกล้คริสตัลเพื่อเปิดคำถาม ตอบผิดได้คำใบ้และลองใหม่ ตอบถูกแต่ละข้อให้คะแนนครั้งเดียว เหรียญไม่เพิ่มคะแนนความรู้

ทำภารกิจและตอบครบ 3 ข้อแล้วกด E ที่ประตูท้ายเกาะเพื่อผ่านด่าน ทางหลักกว้าง มีราวขอบเกาะ หลุมทางเสริมกว้าง 1.2 หน่วย ระยะกระโดดเดินประมาณ 3.1 หน่วยและวิ่งประมาณ 5.4 หน่วย (v เริ่มต้น 7, g=18) เดินอ้อมได้ หัวใจลดเมื่อตกหลุม และกลับ checkpoint อัตโนมัติ ปุ่มพักมีคำสั่งกลับจุดปลอดภัย ปรับกราฟิก เล่นต่อ กลับหน้าแรก และดาวน์โหลดผล

| ด่าน | ภารกิจ | แนวคิด |
| --- | --- | --- |
| 1 ทะเลสาบไอน้ำ | เรียกหยดน้ำ 3 หยด เพิ่มแสง ≥80% | การระเหย ไอน้ำเป็นแก๊สมองไม่เห็น |
| 2 ป่าหมอก | ปรับไอน้ำจริงให้ RH 60% | RH = ไอน้ำจริง/ค่าอิ่มตัวที่อุณหภูมิเดียวกัน ×100 |
| 3 หอคอยอุณหภูมิ | ลด 30 เป็น 20°C ดู RH | ไอน้ำจริงคงที่ แต่ค่าอิ่มตัวลดลงเมื่อเย็น |
| 4 ห้องทดลอง | เลือกเครื่องมือ อ่านค่า จับคู่สถานการณ์ | ไฮโกรมิเตอร์ |
| 5 สวนน้ำค้าง | ลดผิวเย็นถึงจุดน้ำค้าง 15°C | การควบแน่น |
| 6 ปราสาทเมฆ | เรียงลำดับกระบวนการฝน | เย็นจนอิ่มตัว ควบแน่น หยดน้ำโต ตกเป็นฝน |
| 7 มังกรราชัน | ปลดผนึกความรู้สามหัวข้อ | บูรณาการ |

แบบจำลองการทดลองเป็นสื่อการสอน ค่าความหนาแน่นไอน้ำอิ่มตัวในด่าน 3 เป็นค่าประมาณ ตัวเลขแสงแดดเป็นค่าพลังงานในเกม ไม่ใช่แบบจำลองอุตุนิยมวิทยาเชิงปริมาณ อนุภาคเรืองแสงใช้แทนไอน้ำที่มองไม่เห็นจริง

## การบันทึกและผลการเรียน

บันทึกใน localStorage key `humidity-magic-world:v1` เฉพาะเครื่อง/เบราว์เซอร์/เว็บไซต์เดียวกัน ชื่อ ห้อง เลขที่ ด่าน คะแนน เหรียญ และ checkpoint จะอยู่ต่อเมื่อโหลดหน้าใหม่ คะแนนวัดการทำครบหลังลองใหม่ได้ ไม่ใช่ข้อสอบแบบจับคำตอบครั้งแรก เมื่อครบ 7 ด่านแสดงใบประกาศและดาวน์โหลด CSV UTF-8 ที่เปิดใน Excel ได้ การเริ่มใหม่ต้องยืนยันและแทนที่ข้อมูลเดิม ดาวน์โหลดผลก่อนหากต้องการเก็บ

**ไม่มีฐานข้อมูลกลาง ไม่มีการส่งผลให้ครูอัตโนมัติ** ผู้เล่นต้องส่ง CSV ด้วยตนเอง การล้างข้อมูลเบราว์เซอร์จะลบความก้าวหน้า ผู้ใช้เครื่องร่วมกันควรดาวน์โหลดและเริ่มใหม่ก่อนเปลี่ยนคน ไม่ควรใช้ผล localStorage เป็นหลักฐานสอบที่ป้องกันการแก้ไข

## ตรวจสอบ

```sh
npm test
npm run build
# ทดสอบเบราว์เซอร์ โดยเปิด npm run dev ไว้อีก terminal
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
```

Unit tests ตรวจจำนวนด่าน/คำถาม รูปแบบเฉลย การนับคะแนนซ้ำ และข้อมูลเสีย Browser test ใช้ Playwright กับ Chromium ที่ติดตั้งไว้ (กำหนด CHROMIUM_PATH ตามเครื่อง) ทดสอบอินพุตเดิน วิ่ง กระโดด เหรียญ หลุม checkpoint คำตอบผิด/ถูก มินิเกมครบ 7 ด่าน ประตู ใบประกาศ CSV reload และเริ่มใหม่ รวมทั้ง viewport มือถือแนวนอนกับอินพุตจอย/กระโดดจำลอง ใช้ helper วางตัวละครเฉพาะโหมดพัฒนาเพื่อไปยังวัตถุระหว่างตรวจครบทุกด่าน ไม่ใช่การเดินครบทุกเส้นทางด้วยมือ helper นี้ไม่รวมใน production build

ดูผลการตรวจจริงและข้อจำกัดใน `TESTING.md` การจำลองมือถือใน Chromium ไม่รับรอง Safari/iPhone หรือประสิทธิภาพบนอุปกรณ์จริง

## เผยแพร่ Netlify และ Google Sites

1. Push ไฟล์โปรเจกต์นี้ไปยัง repository ของคุณ
2. ใน Netlify เลือก Add new project → Import an existing project แล้วเลือก repository นี้
3. Build command: `npm run build`, Publish directory: `dist` (กำหนดไว้ใน netlify.toml แล้ว)
4. หรือรัน `npm run build` แล้วอัปโหลดโฟลเดอร์ `dist` ไป Netlify แบบ manual deploy
5. เปิดลิงก์ HTTPS ที่ Netlify ให้ ตรวจการเริ่มเกม เสียง และการบันทึกบนมือถือจริง
6. ใน Google Sites เลือกแทรก → ฝัง → URL วางลิงก์ Netlify หรือทำปุ่มเปิดเกมในแท็บใหม่ หาก iframe จำกัด localStorage/เสียง/ขนาดจอ ให้เปิดลิงก์เกมโดยตรง

ไม่ต้องตั้งค่า secret หรือฐานข้อมูล โค้ดพร้อม build สำหรับเผยแพร่ แต่การสร้างไฟล์ใน repository ไม่ใช่การ deploy และยังไม่มีลิงก์สาธารณะจนกว่าจะเผยแพร่จริง
